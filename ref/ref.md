# ⚡ [긴급 요청] UI/UX 텐션 강화 (Juice up!)

> **이유**: 현재 텍스트 위주라 긴박감이 부족함. 시각적 피드백 강화 필요.
> **Phase 2 작업에 아래 내용을 즉시 포함해주세요.**

### 1. 📊 상태바(Status Bar) 도입
- 텍스트(`HP: 50`)를 제거하고, **CSS Progress Bar**로 대체하세요.
- **Color Coding**:
  - 70% 이상: 초록색 (안정)
  - 30% ~ 70%: 노란색 (주의)
  - 30% 미만: **빨간색 + 깜빡임 애니메이션 (위험)**

### 2. 🫨 화면 연출 (Screen FX)
- **Pain Effect**: 라떼의 고통 수치가 높을 때, `<body>` 전체에 `shake` 애니메이션(0.5초 간격 좌우 떨림)을 적용하세요.
- **Danger Overlay**: 체력이 낮을수록 화면 테두리에 붉은색 그림자(`box-shadow: inset red`)가 진해지도록 하세요.

### 3. 🖱️ 인터랙션 무게감 (Long Press)
- '수액 놓기'와 '강제 급여' 버튼은 **버튼을 꾹 누르고 있어야(Hold)** 게이지가 차오르는 방식으로 변경하세요.
- 버튼을 누르는 동안 고양이가 떠는 애니메이션(`shake-cat`)을 추가하세요.
