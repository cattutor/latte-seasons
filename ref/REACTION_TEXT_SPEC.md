# 라떼의 계절 — 선택지별 반응 텍스트 사양서

> **목표**: 모든 선택에 라떼 또는 보호자의 구체적 반응을 붙인다.  
> "선택 → 숫자 변화"가 아니라 "선택 → 라떼가 반응 → 감정"이 매 턴 일어나야 한다.  
> 간병 행위에는 라떼의 물리적 반응, 생활 선택에는 보호자의 내면 묘사.

---

## 1. 구현 방식

### EVENTS 내 각 choice에 reaction 필드 추가

```javascript
{ label: "등을 충분히 데워주고 천천히",
  delta: { hp: 4, comfort: 3, sanity: -2, money: -2, bond: 2 },
  reaction: "라떼가 눈을 감고 힘을 뺐다. 믿고 있다." }
```

### getReactionText 수정: choice.reaction 우선

```javascript
function getReactionText(choice, scene) {
  // 1순위: 시스템 메시지 (Collapse 경고 등)
  if (state.systemMessages && state.systemMessages.length > 0) {
    return state.systemMessages.shift();
  }
  // 2순위: 선택지 고유 반응 (신규)
  if (choice.reaction) {
    return choice.reaction;
  }
  // 3순위: 기존 delta 기반 범용 반응 (폴백)
  // ... (기존 로직 유지)
}
```

이렇게 하면 reaction이 있는 선택지는 고유 반응이, 없는 선택지(위기 이벤트 등)는 기존 범용 반응이 나옵니다.

---

## 2. 반응 텍스트 작성 원칙

- 간병 행위(수액, 급여, 안기) → **라떼의 물리적 반응** (눈, 귀, 몸, 소리)
- 생활 선택(출근, 재택, 기록) → **보호자의 내면 묘사** (감정, 풍경, 감각)
- 부정적 선택(기록 생략, 방치) → **부재의 무게** (빈 공간, 침묵, 자책)
- hiddenPoint 선택 → **조용하지만 깊은 교감** (체온, 숨소리, 시선)
- 문장은 1~2문장, 최대 40자 내외

## 7. getReactionText 수정 코드

```javascript
function getReactionText(choice, scene) {
  // 1순위: 시스템 메시지 (Collapse 경고 등)
  if (state.systemMessages && state.systemMessages.length > 0) {
    return state.systemMessages.shift();
  }
  
  // 2순위: 선택지 고유 반응 (신규 — 핵심 변경)
  if (choice.reaction) {
    return choice.reaction;
  }
  
  // 3순위: 위기/돌발 이벤트 반응 (기존 유지)
  if (scene && scene.isCrisis) {
    const crisisReactions = [
      "심장이 쿵 내려앉았지만, 지금은 손을 먼저 움직여야 한다.",
      "패닉을 누르고 순서대로 대응한다.",
      "짧은 몇 분이 길게 늘어난다.",
    ];
    return crisisReactions[Math.floor(Math.random() * crisisReactions.length)];
  }
  if (scene && scene.isRandomDawn) {
    return "예상치 못한 변수가 하루의 결을 바꾼다.";
  }
  
  // 4순위: delta 기반 범용 반응 (기존 유지, 폴백)
  if (choice.delta.hp >= 5) return "라떼의 숨결이 조금 더 안정됐다.";
  // ... (기존 로직 그대로) ...
}
```
