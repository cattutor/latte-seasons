# 라떼의 계절 프로토타입

게임 기획서(`라떼의계절_GDD_8bit.docx`)를 기반으로 만든 웹 프로토타입입니다.

## 실행 방법

1. `D:\text\index.html`을 브라우저에서 엽니다.
2. 선택지를 눌러 28일 동안 진행합니다.
3. 종료 시 엔딩(A/B/C/Hidden)과 로그를 확인합니다.

## 구현된 핵심 요소

- 28일 로그형 진행
- 자원 5종: `HP`, `Comfort`, `Sanity`, `Money`, `Bond`
- 선택지 기반 상태 변화
- 배드엔딩 없이 분기형 엔딩
- 기록 내보내기(`.txt`)

## 파일 구성

- `index.html`: 게임 UI
- `style.css`: 8비트 풍 HUD/화면 스타일
- `script.js`: 게임 로직(시나리오, 자원, 엔딩, 로그)
