# 🛠️ Phase 3 미니게임 기능 복구 및 시스템 통합 지시서

> **현상**: Phase 3 로직(수액 타이밍, 19스푼 급여, CCTV 퀴즈)이 코딩되었으나, 실제 게임 내에서 실행되지 않거나 화면에 표시되지 않음.

## 1. 🔍 긴급 진단 및 복구 (Debugging)
**[Action]** 아래 항목을 전수 조사하여 미니게임 실행 체인을 복구하세요.

### A. 실행 트리거(Trigger) 연결 확인
- `script.js` 내의 `handleChoice` 또는 `advanceTurn` 직후에 **현재 시간대(`state.timeSlot`)와 선택지 키워드**를 감지하여 미니게임을 호출하는 로직이 살아있는지 확인하세요.
- 예: `if (choice.label.includes("수액")) { startIvMinigame(); }` 식의 조건문이 누락되었는지 체크할 것.

### B. DOM 오버레이 가시성 (z-index)
- `style.css`에서 미니게임 오버레이(`.minigame-overlay`)의 `z-index`를 **100 이상**으로 설정하여 메인 화면에 가려지지 않게 하세요.
- 오버레이의 `display: none`이 `display: flex`로 정확히 전환되는지 `script.js`의 DOM 제어 코드를 수정하세요.

### C. ID 매칭 전수 조사
- `index.html`에 추가된 미니게임용 HTML 블록의 ID(예: `timing-bar`, `spoon-count`)와 `script.js`에서 호출하는 `document.getElementById`의 인자가 정확히 일치하는지 확인하세요.

---

## 2. 🎮 미니게임별 세부 수선 (Optimization)

### 3-1. 수액 타이밍 게임 (새벽/오전)
- 바늘 각도를 맞추는 **타이밍 바 애니메이션**이 `requestAnimationFrame` 또는 `setInterval`을 통해 실시간으로 갱신되도록 보강하세요.
- 'Perfect' 판정 영역(Safe Zone)의 너비를 난이도에 따라 조정 가능하도록 변수화하세요.

### 3-2. 강제 급여 리듬 게임 (저녁)
- 19스푼 카운터가 클릭 시마다 즉각 업데이트되지 않는 문제를 수정하세요.
- 입을 벌리는 애니메이션 프레임과 클릭 판정 시간(Window)이 어긋나지 않게 동기화하세요.

### 3-3. CCTV 관찰 퀴즈 (오후)
- 블러(Blur) 처리된 텍스트가 CSS `filter: blur()`와 연동되어 정답을 맞혔을 때 서서히 선명해지는 연출을 추가하세요.

---

## 3. 🎨 시각적 패널티 및 레이아웃 유지
- **실패 연출**: 미니게임 실패 시 화면이 붉게 깜빡이는 `minigame-fail` 클래스가 `body` 전체에 적용되도록 하세요.
- **레이아웃 고정**: 미니게임 실행 중에도 우측의 '간호 일지' 영역이 흐트러지지 않도록 `game-shell`의 그리드 레이아웃을 고수하세요.

---

**[최종 요청]**
미니게임이 포함된 **`index.html`, `style.css`, `script.js` 전체 코드를 하나로 통합하여 다시 작성**해줘. 특히 미니게임이 끝난 후 스탯 결과가 일지에 자동으로 기록되고 다음 턴으로 자연스럽게 넘어가는지 확인해줘.
