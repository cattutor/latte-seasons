# 🛠️ [긴급] 레이아웃 높이 고정 및 일지 내부 스크롤 구현 요청

> **문제 현상**: 간호 일지(로그)가 길어짐에 따라 우측 영역(`side-area`)의 높이가 무한정 늘어남. 이로 인해 선택지 버튼이 화면 아래로 밀려나며 전체 웹 페이지 스크롤이 발생하는 등 게임 진행 방해.

## 1. 🎯 주요 목표
- 게임 전체 화면(`game-shell`)의 높이를 고정하고, 브라우저 스크롤을 방지함.
- 간호 일지 영역만 내부적으로 스크롤되도록 변경하여 UI 요소를 한 화면에 고정함.

## 2. 📝 상세 수정 지침

### A. CSS 레이아웃 고정 (`style.css`)
- **전체 앱 고정**: `#app`에 `height: 100vh;`와 `overflow: hidden;`을 적용하여 브라우저 스크롤을 원천 차단할 것.
- **게임 쉘 규격 고정**: `.game-shell`에 `height: min(750px, 100vh - 20px);`을 적용하여 화면 높이에 맞게 크기를 제한할 것.
- **사이드바 구조 변경**: 
    - `.side-area`에 `display: grid; grid-template-rows: 1fr auto;`를 적용하여 상단 로그 영역이 유동적으로 차지하고, 하단 컨트롤 패널은 고정되게 할 것.
    - `.side-area` 자체에 `height: 100%; overflow: hidden;`을 설정할 것.
- **로그 패널 스크롤**: `.log-panel`에 `overflow-y: auto;`를 부여하여 일지가 길어질 때 내부에서만 스크롤이 발생하게 할 것.

### B. JS 자동 스크롤 유지 (`script.js`)
- 새로운 로그가 추가될 때마다 `.log-panel`의 스크롤이 최하단(최신 기록)으로 이동하도록 기존의 `scrollIntoView` 로직이 정상 작동하는지 재확인할 것.

## 3. 🎨 시각적 편의성 보강
- **로그 테이블 헤더 고정**: 테이블 헤더(`th`)에 `position: sticky; top: 0;`을 적용하여 스크롤 시에도 항목 이름이 보이게 유지할 것.
- **영역 구분**: `.log-panel`과 `.control-panel` 사이에 명확한 경계선(`border-top`)을 추가하여 시각적으로 분리할 것.
