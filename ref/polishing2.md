# 🎭 Phase 4: 최종 시스템 통합 및 엔딩 로직 구축 (Final Sync)

> **상태 알림**: 본 요청은 전체 프로젝트의 마지막 통합 작업입니다. 현재 구현된 데이터 구조를 보존하며, 아래의 감성 연출 및 엔딩 시스템을 완벽하게 주입해 주세요.

## 1. ⌨️ 타이프라이터 연출 (Narrative Feedback)
- **대상**: 메인 지문(`#sceneText`) 및 미니게임 결과 텍스트.
- **기능**: 텍스트가 한 번에 나타나지 않고 30ms 간격으로 한 글자씩 출력되는 `typeText(element, text)` 함수를 구현하세요.
- **스킵**: 텍스트 출력 중 화면을 클릭하면 전체 텍스트가 즉시 표시되도록 설계하세요.

## 2. 🌅 멀티 엔딩 및 크레딧 시스템 (The Ending)
- **트리거**: `state.day`가 28일(D-Day)에 도달하거나 HP가 0이 되었을 때 실행.
- **엔딩 조건**:
  - **기적(Miracle)**: HP > 50 AND 유대감(Bond) > 80 (라떼가 기적적으로 기력을 회복함)
  - **평온한 이별(Peaceful)**: 편안함(Comfort) > 70 (고통 없이 평온하게 별이 됨)
  - **회한(Regret)**: 위 조건 미충족 (준비되지 않은 갑작스러운 이별)
- **연출**: 화면이 서서히 세피아 톤으로 페이드아웃되며, 그동안 작성된 간호 일지가 하단에서 상단으로 자동 스크롤되는 엔딩 레이어를 활성화하세요.

## 3. ⚡ 시각적 타격감 강화 (Visual Juice)
- **성공 피드백**: 미니게임 Perfect 판정 시 `#app`에 `flash-screen` 효과를 0.1초간 부여하고, 라떼 주변에 따뜻한 입자 효과를 추가하세요.
- **위기 피드백**: HP 25% 이하 시 화면 전체가 미세하게 떨리는 `pain-shake` 애니메이션을 상시 적용하고, 붉은색 비네팅 강도를 높이세요.

## 4. 🎵 오디오 엔진 구조 (Placeholder)
- `playBGM(chapter)` 함수를 생성하여 챕터 전환 시 호출되도록 배치하세요.
- 위독 상태(`hp < 20`) 시 심박음(`heartbeat.mp3`)이 루프 재생될 수 있는 오디오 제어 변수를 확보하세요. (현재는 경로만 비워둘 것)

## 🛠️ 개발 가이드라인 (중요)
- **데이터 보존**: `chapterEvents` 등 기존의 방대한 데이터 배열은 절대 삭제하거나 수정하지 말고 그대로 유지하세요.
- **레이아웃 유지**: 이전 작업에서 완성한 '중앙 정렬 Grid 레이아웃'과 '일지 내부 스크롤'이 깨지지 않도록 CSS 규격을 엄수하세요.
- **메모리 최적화**: 코드가 너무 길어질 경우, 반복되는 스타일이나 로직은 함수화하여 최대한 압축해서 작성해 주세요.
